# Money Manager

A modern and secure personal finance management backend built using Java Spring Boot. The project is designed to help users efficiently manage income, expenses, and financial records through scalable REST APIs.


---

🚀 Features

User Authentication & Authorization

Income & Expense Management

Category-Based Transaction Tracking

Secure RESTful APIs

Database Integration with JPA/Hibernate

Validation & Exception Handling

Clean and Modular Architecture

Scalable Backend Structure



---

🛠 Tech Stack

Java

Spring Boot

Spring Security

Spring Data JPA

MySQL

Maven



---

🌐 API Testing

Tested and optimized using tools like Postman and Swagger UI.
